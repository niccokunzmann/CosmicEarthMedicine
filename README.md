# Cosmic Earth Medicine

A site for Yemaya Rodriguez

## Build

1. Install Hugo
2. clone repo

    ```shell
    git clone
    cd CosmicEarthMedicine
    git submodule init
    git submodule update
    ```

3. Run the server

    ```shell
    hugo server -D -N --noBuildLock --bind 0.0.0.0 --noHTTPCache
    ```
